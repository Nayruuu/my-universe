# Illustration licenses

## Paris horizon landmarks

`highpoints-of-paris.svg` is an unmodified local copy of
[Highpoints of Paris](https://commons.wikimedia.org/wiki/File:Highpoints_of_Paris.svg) by
[IIVQ](https://commons.wikimedia.org/wiki/User:IIVQ), licensed under
[CC BY-SA 2.5](https://creativecommons.org/licenses/by-sa/2.5/).

Universe Map reuses the source SVG's Notre-Dame, Tour Montparnasse, Grande Arche, Arc de Triomphe,
and Sacré-Cœur groups as individually positioned fragments. Their original colours are filtered at
render time to integrate them into the illustrative night skyline. Each fragment preserves its
source aspect ratio, while its vertical scale follows the documented physical-height ratios listed
in `data-sources/README.md`. This layout is an adaptation and is distributed under the same CC BY-SA
2.5 license.

The separately rendered Eiffel Tower uses GDJ's
[Eiffel Tower Silhouette](https://commons.wikimedia.org/wiki/File:Eiffel_Tower_Silhouette.svg),
released under the
[CC0 1.0 public-domain dedication](https://creativecommons.org/publicdomain/zero/1.0/).
