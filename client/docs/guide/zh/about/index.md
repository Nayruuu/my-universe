# 关于Universe Map

Universe Map是由**Nayruuu**独立构思、设计和开发的项目。它希望通过一张连续的三维互动地图，
让更多人直观感受宇宙的尺度与丰富性，同时清楚区分真实观测、天文计算、科学模拟和为了可读性
进行的视觉适配。探索者既可以欣赏画面，也能够知道每一种表示背后的可信度和限制。

这个项目融合了软件架构、科学数据整理、实时三维渲染、界面设计、无障碍支持、性能优化、文档
编写和多语言翻译。它以免费的静态网页应用形式提供，因此只需一个现代浏览器，无须账户或专业
软件便能开始探索。应用优先在浏览器本地运行，而不是依赖收集个人数据的业务后端，从而保持体验
轻量、直接且透明。

## 为什么要制作这张地图？

许多天文工具专注于某一个尺度，例如从地球看到的天空、单独的行星系统，或者供科学分析使用的
数据目录。Universe Map尝试探索一个互补的想法：能否在同一套地图体验中，从一颗卫星和一颗
行星出发，连续前往太阳系、附近恒星、银河系、邻近星系以及已有文献记录的宇宙网结构？这种连续
导航能够帮助人们建立不同天文尺度之间的关系，而不仅仅是观看彼此孤立的场景。

这并不意味着每一幅画面都被当作现实的精确复制品。为了清晰连接相差极大的尺度，有时需要使用
自适应尺寸、程序化密度、渐进过渡或说明性的材质。项目会标明这些选择的性质和数据来源，让视觉
上的震撼与科学透明度能够同时存在，也避免把模拟或装饰内容误认为精确观测。

## 支持这段探索旅程

Universe Map始终可以免费探索，源代码也公开在
[GitHub](https://github.com/Nayruuu/my-universe)。请作者喝咖啡从来不是使用地图的条件，但这份
支持能够帮助Nayruuu投入更多时间，继续改进天文目录、科学测试、渲染质量、无障碍体验、多语言
翻译、技术文档，以及从行星尺度通往宇宙学尺度的漫长过渡。
