# 快速开始

Universe Map完全运行在现代浏览器中，不需要账户，也不调用应用后端。天文目录、纹理和
模型均作为静态文件提供，并随着相机尺度变化逐步加载。

## 打开地图

访问[super-universe.app](https://super-universe.app/zh/)。初始视图只加载渲染引擎和精简的
清单；体积较大的恒星与星系数据会在需要时才下载。

首次体验建议：

1. 使用支持WebGL 2的现代桌面浏览器；
2. 如果使用较新的GPU，将图形质量保持为**高**；
3. 等待加载提示消失后再开始移动；
4. 在可见天体上滚动，或点击它的名称。

地图也支持触摸操作，并会在小型设备上自动降低视觉密度。

## 界面概览

| 区域     | 功能                                                             |
| -------- | ---------------------------------------------------------------- |
| 顶部搜索 | 查找行星、卫星、恒星、系外行星、星系、黑洞、超新星和大尺度结构。 |
| 尺度路径 | 显示当前天文层级，并可直接前往上级。                             |
| 天体卡片 | 显示来源、别名、物理属性、可信度和聚焦操作。                     |
| 浮动控件 | 缩放、返回地球或太阳，以及切换轨道、星座和名称。                 |
| 时间轴   | 编辑UTC时间、播放或暂停、选择速度并浏览食事件。                  |
| 地图比例 | 显示适合当前相机环境的屏幕尺度。                                 |

## 第一次旅行

1. 搜索**地球**并选择结果；
2. 使用滚轮或双指缩放向外穿过太阳系；
3. 选择**太阳**，继续缩小至恒星邻域；
4. 从尺度菜单选择**银河系**；
5. 继续前往本星系群、附近宇宙和宇宙大尺度结构；
6. 使用层级路径返回太阳系。

逻辑目标决定地图层级和距离限制，几何旋转中心决定相机环绕的中心，选择项决定信息卡片。
明确聚焦后三者通常对齐，但指针缩放和自由空间导航可以使它们分离。

## 从地面地平线观测恒星

搜索**天狼星**等恒星，打开信息卡并选择**从地球定位**。本地天空视图会采用地图的日期和
观测地点。拖动可环顾四周，滚轮或双指缩放可改变视场，选择**重新居中**可找回目标。这些是
天象仪控件：地平线视图打开时，滚轮不会触发语义地图尺度切换或最小距离移动。地点选择器
提供全球461个静态观测地点；观测者与天象仪视图都会保留在分享URL中。**使用我的位置**仅在
用户选择后请求浏览器权限，将获得的坐标取整到小数点后三位（约100米），并使用同一套可分享的
观测者状态。

月球和可见行星会复用地图视图中的Three.js对象、材质、照明，以及有来源或经过适配的纹理。系统会
根据所选地点与时刻计算站心方向和角直径。用于辨认小行星的有限最小显示尺寸会明确标为示意，不能
理解为真实角直径。

地平线会随视线方位角转动并固定于地面，而天空随时间变化。8个重点城市拥有手工组合的
视觉环境；目录中的每个地点都会按需从区域静态包加载4个附近地标。即使名称、坐标或高度
有文献来源，也不代表画面经过测量：地形、城市灯光、天际线层和通用地标轮廓均明确属于
示意表达。该视图不能替代实测地形遮挡、天气资料、历史城市复原或专业观测规划工具。

## 图形质量与分享

**低**会减少粒子、纹理、体积和分块；**中**平衡细节与GPU开销；**高**启用当前尺度允许
的最丰富表达。质量不会改变科学坐标或可信度。

分享按钮生成的URL会保留目标、选择项、日期、缩放、时间模式、质量、名称密度、轨道、
星座和标签。URL会经过短暂延迟更新，而不是每一帧都更新。
