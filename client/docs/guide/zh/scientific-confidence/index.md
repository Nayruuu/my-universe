# 科学可信度

Universe Map不会把所有可见元素都当作同等确定的事实。每个天体或表达都会带有以下六种
可信度标签之一。

## 可信度级别

| 级别           | 含义                           | 示例                     |
| -------------- | ------------------------------ | ------------------------ |
| `observed`     | 基于测量或公开目录             | 恒星方向或星系距离       |
| `calculated`   | 来自天文计算                   | 所选日期的行星位置       |
| `extrapolated` | 延伸已测运动或简化轨道         | 超出参考历元的自行       |
| `simulated`    | 科学模型或连续性模型的结果     | 可选的宇宙密度包络       |
| `procedural`   | 为补充视觉表达而生成           | 自适应星系中的粒子分布   |
| `illustrative` | 为可读性设计，而非严格物理比例 | 可见半径、光晕或星座连线 |

天体卡片会同时显示级别和来源说明。同一个可见天体可以组合观测位置、计算姿态和示意的
视尺寸。

## 科学坐标与视觉坐标

源数据保留千米、天文单位、光年、秒差距、千秒差距和百万秒差距等明确单位。引擎在分层
参考系中进行转换。如果全局使用物理比例，大多数天体都会小于一个像素，因此视觉半径和
部分尺度间距离会单独适配。

## 参考历元、参考系与视觉真实感

目录位置属于有文献说明的参考系和历元，例如J2000恒星坐标、日心行星星历、银心模型和
由红移推导的位置。Universe Map不会把互不兼容的巡天结果合并为声称精确的单一几何。

纹理、泛光、大气、吸积辐射、星系形态、超新星颜色和黑洞透镜有助于理解，但并非测量。
黑洞透镜是定性的，星座线是文化约定，未解析的宇宙网络连续性来自模拟，星系粒子分布也
可能是示意性的。

本地图适合探索、教育和视觉比较，不适用于航天器导航、专业天体测量、观测安全决策或
高精度食预测。
