# 路线图

_最后审阅：2026年9月10日。_

本页是Universe Map的正式公开路线图。它描述成果与验证门槛，而不是承诺固定发布日期。科学准确性、
清晰导航、稳定帧时间和完全静态的浏览器架构，是每一项演进都必须满足的约束。

## 状态说明

| 状态   | 含义                                         |
| ------ | -------------------------------------------- |
| 已交付 | 当前应用已经提供，并受到自动化测试保护       |
| 当前   | 现有体验接下来要改进的项目                   |
| 下一步 | 需要先定义科学契约或完成实体设备测量         |
| 已推迟 | 只有出现新来源、新数据或更密集目录时才有价值 |

## 已交付

- **地球观测者天象仪**提供可自由环视的10,000颗HYG恒星、现代星座、高度与方位角、固定于指针的
  102°至2°视场、可由URL恢复的461个观测地点、经用户同意并取整到小数点后三位的浏览器定位，
  以及示意性的本地场景环境。
- 从天象仪返回3D地图会在同一渲染器中用2.4秒拉远，保留初始视线并将地球设为旋转中心。
  该示意动画可被输入立即打断，并尊重减少动态效果的偏好。
- 卡片、搜索、规划器和时间栏适配窄屏与低矮屏幕，支持紧凑和展开状态。关闭操作保留在标题栏，
  轨道操作移至轨道数据旁。移除重复的橙色提示，但保留科学说明。滚轮测试等待惯性结束，并验证
  距离下限处的新手势，不改变相机控制本身。
- 按需运行的本地观测规划器会按高度排列可见的月球、行星和目录卫星，并评估目录中最亮的48颗恒星，
  最多推荐8颗当前可见恒星。选择建议会打开已有天体详情并将天空重新居中。系统会采用计算地平线和
  可用的地形遮挡。当前目标现有24小时计算高度曲线，包含升起、中天、落下、USNO曙暮光区间、月光
  干扰、明确标为示意的最佳窗口指数，以及同时移动共享时间和相机的操作。曲线目标可从同一本地目录中
  更换，预览时不会移动当前天空；只有执行该操作才会确认目标、共享时间和相机。紧凑对比会将同一计算
  应用于连续七晚，并以满分100的可比较示意指数自动突出最佳夜晚。界面会显示高度、天空暗度、月光和
  地形净空，再通过直接操作前往以5分钟步长局部细化后的最佳时刻。实时天气、光污染以及未经测量的本地
  障碍物不在模型范围内。
- 每个固定目录地点都有一个360°遮挡剖面，由权威的NOAA/NCEI ETOPO 2022 v1 60角秒表面地形
  产品计算而成。紧凑剖面按需加载，可隐藏模型地形之后的恒星、月球、行星和卫星；建筑、植被、微地形
  和自由坐标地点明确不属于该模型。三个计算距离层（0至30、30至100、100至300公里）赋予轮廓
  纵深感；颜色与照明均为风格化表现。
- 月球、七颗可见行星和目录中的其他20颗卫星会复用已有Three.js对象、材质、照明和延迟加载纹理。
  站心方向与角直径使用物理轨道距离：伽利略卫星位置标为计算值，使用J2000平均根数的其余16条轨道
  标为外推。卫星会在视场不大于12°或被直接选中时显示，以避免广角重叠；为可读性设置的最小尺寸仍
  明确标为示意。
- 银河系的外观与内部穿行使用同一个固定银心坐标点云，不使用银河图片或沿相机路径构造的隧道。
  圆盘与太阳共享规范尺度：圆盘直径10万光年，太阳距银心8.178 kpc。相机路线与滚轮灵敏度不变。
  细小颗粒产生透视视差，额外的有界GPU批次补充近距离细节。金色棒、象牙色核、蓝白旋臂与暗尘带
  都是示意密度和颜色，不是逐颗Gaia测量，也不是黑洞发出的光。
- 局部坐标系在不可见的情况下于3,600至2,400场景单位展开。HYG/Gaia在坐标固定后于900至90
  单位出现。银河点云于220至70单位淡出，行星和轨道于240至90单位出现。近距离细节在停止或
  反向行进时都保留相同位置。
- 外部星系也采用具有旋涡、椭圆或不规则密度的固定点云，可从多个方向观看。目录位置保持不变，
  内部点和颜色则为示意。选中星系仍可查看信息卡并交互，不再用巨大的行星选择圆环遮盖点云。
- Gaia DR3层级把2,923,790个经过质量筛选的来源表示为恒星邻域总览所用的远距离512秒差距计算
  聚合和133,526个实测来源样本。每个细化的512秒差距叶节点保留最亮的32个来源，再以确定性的均匀
  选择补足到最多96个点。由视野和质量限制的细化只加载可见分支，在模块Worker中完成验证，并以
  零拷贝方式传输类型化数组；系统不会为每个来源创建Three.js对象。保留的Gaia样本会保存来源ID，
  并可直接在共享GPU批次中选择和聚焦；信息卡显示实测G、BP−RP以及由视差倒数计算的距离。它们仍不
  进入全局搜索和标签，而聚合单元保持匿名。采样视场并不完整。缩小时，详细样本会平滑过渡为计算根节点，并以克制的亮度
  保留到本星系群；同时，局部体积通过对数缩放自然融入银河系盘。
- HYG的J2000直角速度现会按时间传播共享恒星目录、观测者天空与星座图形；可信度明确标为外推，
  有效范围限制为±10,000儒略年。
- 时间模式**接收到的光**现在把所选日期视为接收日期。它使用Astronomy Engine从地球回溯太阳、
  月球和行星，并以太阳系质心为观测者，为每颗HYG恒星求解各自的延迟时刻。受支持的轴向自转使用
  该发射时刻，天体卡片显示延迟和发射日期，HYG模型保留明确的±10,000儒略年限制。
- 伽利略卫星使用从地球接收时刻的Astronomy Engine。其他有文献根数的卫星、矮行星、小行星和彗星
  用现有JPL二体根数迭代求解几何光行时；置信度保持外推，视觉距离放大不参与科学计算。
- 有文献距离的系外行星系统现在共享由NASA已发布宿主星距离计算的太阳系质心延迟。宿主星静态方向不变，
  局部行星轨道在该发射时刻计算，但相位明确保持示意；没有发布距离的系统保持同时刻。
- 近邻星系现在使用目录距离的几何光行时。Cosmicflows-4距离模数按光度距离处理，大尺度结构地图距离按
  共动距离处理；两者都在有文档说明的平直ΛCDM模型中反演。天体卡片显示推断的红移和回望时间，位置与
  静态外观保持不变，结果明确标为外推。
- 已发表的宇宙墙、概率吸引盆地、吸引子和排斥子保留独立来源与符号，不与Tempel纤维网络合并。
- 冷启动、Tempel过渡、资源稳定性和帧稳定性都有可重复的浏览器基准。
- 已在使用真实Metal渲染器的Apple M5 Max上完成高端实体设备重复基准，分别记录三次启动、Tempel和
  冷帧测量，以及三个预热后资源周期。该结果不作为其他设备级别的证据。
- 专用观测天象仪基准现已覆盖真实天空平移、重新居中、以木星为锚点切换到共享解析行星显示，以及缩小。
  三次高端Retina实体设备运行均在高质量DPR 1.5上限下通过，且没有长帧。另一个明确标为模拟的
  CPU 4×/6×压力矩阵也已通过，仅用于衡量回归余量。
- 五项手动性能协议现在共享同一份带版本号的JSON证据报告，记录源码状态、主机、渲染器、配置、样本和
  摘要。实体设备专用保护会在写出报告前拒绝模拟、软件渲染或未分类的测量。要求干净检出的活动运行器
  会依次执行五项协议，并将五个文件绑定到可用SHA-256验证的清单中。
- 另一个要求干净检出的命令现在会对五项协议执行同主机中端和低端回归活动：中等质量采用CPU 4×，
  低质量采用CPU 6×。独立模拟清单绑定十份报告，并声明GPU、内存、驱动、带宽和热行为仍属于源主机。
- 四个补充目录现在由专用模块Worker获取和解码，类型化数组缓冲区以零复制方式传回。准备阶段不会创建
  场景资源；完成后，主线程上的注册表、搜索、几何体和GPU安装需要重新等待相机稳定1.2秒。每次过渡都会
  重新计时，观测模式会完全暂停后台安装，而显式请求的目录目标仍会立即加载。2026年8月28日版本`27db0e1`的干净活动通过了
  全部十份报告。中等质量/CPU 4×尺度路径的p95为9.3 ms，最差帧66.5 ms；低质量/CPU 6×的p95为
  16.6〜16.7 ms，最差帧83.4 ms。两个配置的观测路径都能3/3解析木星，资源计数也没有漂移。

## 当前优先事项

- 对照参考影像确认旋臂、核心和内部穿行的最终视觉效果。浏览器检查覆盖视角、空间稳定性和星系选择；
  技术上可见不等于审美验收。
- 调查9月10日本地诊断记录的帧预算超限，之后在干净版本上重跑活动。上述10/10数据属于8月28日
  的历史基线，不代表当前未提交状态已通过。模拟配置不能证明其他设备的性能；中低端实体设备验证仍可选。

天象仪仍是所选观测地点的独立站心投影。时间地图接收到的光对受支持的太阳系天体使用地球观测者，
对HYG恒星和有文献距离的系外行星系统使用太阳系质心。

## 有意推迟

- 只有权威形状产品足以证明下载、解码、署名和渲染成本合理时，才增加新的不规则天体轮廓或网格。
