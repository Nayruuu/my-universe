# 路线图

_最后审阅：2026年8月27日。_

本页是Universe Map的正式公开路线图。它描述成果与验证门槛，而不是承诺固定发布日期。科学准确性、
清晰导航、稳定帧时间和完全静态的浏览器架构，是每一项演进都必须满足的约束。

## 状态说明

| 状态   | 含义                                         |
| ------ | -------------------------------------------- |
| 已交付 | 当前应用已经提供，并受到自动化测试保护       |
| 当前   | 现有体验接下来要改进的项目                   |
| 下一步 | 需要先定义科学契约或完成实体设备测量         |
| 已推迟 | 只有出现新来源、新数据或更密集目录时才有价值 |

## 已交付

- **地球观测者天象仪**提供可自由环视的10,000颗HYG恒星、现代星座、高度与方位角、固定于指针的
  102°至2°视场、可由URL恢复的461个观测地点、经用户同意并取整到小数点后三位的浏览器定位，
  以及示意性的本地场景环境。
- 每个固定目录地点都有一个360°遮挡剖面，由权威的NOAA/NCEI ETOPO 2022 v1 60角秒表面地形
  产品计算而成。紧凑剖面按需加载，可隐藏模型地形之后的恒星、月球和行星；建筑、植被、微地形
  和自由坐标地点明确不属于该模型。三个计算距离层（0至30、30至100、100至300公里）赋予轮廓
  纵深感；颜色与照明均为风格化表现。
- 月球和七颗可见行星会复用已有Three.js对象、材质、照明和延迟加载纹理。系统计算站心方向与角直径；
  为可读性设置的最小尺寸仍明确标为示意。
- 恒星和银河系会随缩放连续增加细节。导航也会清除已经脱离视觉上下文的目标和选择项。
- HYG的J2000直角速度现会按时间传播共享恒星目录、观测者天空与星座图形；可信度明确标为外推，
  有效范围限制为±10,000儒略年。
- 时间模式**接收到的光**现在把所选日期视为接收日期。它使用Astronomy Engine从地球回溯太阳、
  月球和行星，并以太阳系质心为观测者，为每颗HYG恒星求解各自的延迟时刻。受支持的轴向自转使用
  该发射时刻，天体卡片显示延迟和发射日期，HYG模型保留明确的±10,000儒略年限制。
- 伽利略卫星使用从地球接收时刻的Astronomy Engine。其他有文献根数的卫星、矮行星、小行星和彗星
  用现有JPL二体根数迭代求解几何光行时；置信度保持外推，视觉距离放大不参与科学计算。
- 有文献距离的系外行星系统现在共享由NASA已发布宿主星距离计算的太阳系质心延迟。宿主星静态方向不变，
  局部行星轨道在该发射时刻计算，但相位明确保持示意；没有发布距离的系统保持同时刻。
- 近邻星系现在使用目录距离的几何光行时。Cosmicflows-4距离模数按光度距离处理，大尺度结构地图距离按
  共动距离处理；两者都在有文档说明的平直ΛCDM模型中反演。天体卡片显示推断的红移和回望时间，位置与
  静态外观保持不变，结果明确标为外推。
- 已发表的宇宙墙、概率吸引盆地、吸引子和排斥子保留独立来源与符号，不与Tempel纤维网络合并。
- 冷启动、Tempel过渡、资源稳定性和帧稳定性都有可重复的浏览器基准。
- 已在使用真实Metal渲染器的Apple M5 Max上完成高端实体设备重复基准，分别记录三次启动、Tempel和
  冷帧测量，以及三个预热后资源周期。该结果不作为其他设备级别的证据。
- 专用观测天象仪基准现已覆盖真实天空平移、重新居中、以木星为锚点切换到共享解析行星显示，以及缩小。
  三次高端Retina实体设备运行均在高质量DPR 1.5上限下通过，且没有长帧。另一个明确标为模拟的
  CPU 4×/6×压力矩阵也已通过，仅用于衡量回归余量。
- 五项手动性能协议现在共享同一份带版本号的JSON证据报告，记录源码状态、主机、渲染器、配置、样本和
  摘要。实体设备专用保护会在写出报告前拒绝模拟、软件渲染或未分类的测量。要求干净检出的活动运行器
  会依次执行五项协议，并将五个文件绑定到可用SHA-256验证的清单中。
- 另一个要求干净检出的命令现在会对五项协议执行同主机中端和低端回归活动：中等质量采用CPU 4×，
  低质量采用CPU 6×。独立模拟清单绑定十份报告，并声明GPU、内存、驱动、带宽和热行为仍属于源主机。

## 当前优先事项

- 在引入性能敏感改动时，记录并比较自动中端和低端模拟活动的干净清单。若能获得代表性硬件，实体设备
  验证仍为可选项；模拟配置是回归门槛，不是设备性能声明。只有测量结果证明成本合理时，才增加着色器
  预编译或更重的后备路径。

天象仪仍是所选观测地点的独立站心投影。时间地图接收到的光对受支持的太阳系天体使用地球观测者，
对HYG恒星和有文献距离的系外行星系统使用太阳系质心。

## 有意推迟

- 已准备的恒星聚合层级会保持休眠，直到更密集的原始目录确实需要跨尺度可见表达。启用时必须将
  准备过程移入Web Worker，并避免不可见的网络或GPU工作。
- 只有权威形状产品足以证明下载、解码、署名和渲染成本合理时，才增加新的不规则天体轮廓或网格。

## 产品边界
