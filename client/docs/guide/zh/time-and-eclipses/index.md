# 时间与日月食

时间轴内部使用数值形式的儒略日。界面接受UTC民用日期，并在传给渲染引擎之前进行转换。

## 时间控制

你可以输入UTC日期和时刻、播放或暂停、返回当前时间、选择适合当前尺度的时间倍速，并
浏览有记录的过去和未来食事件。暂停时，轨道位置和轴向自转都会固定。恢复播放后，二者
均由同一个内部时间计算，而不是根据渲染帧数推进。

## 时间模式

**所选日期的状态**会把所有天体显示在同一个估算时刻，是当前已经实现的主要模式。

**接收到的光**把所选日期视为接收日期。受支持的太阳系天体以地球为观测者，HYG恒星以太阳系
质心为观测者。每个受支持天体都在各自的发射时刻计算，其轴向自转也使用同一时刻。天体卡片会
显示计算得到的光行时和发射日期。

当前范围包括太阳、月球、行星、伽利略卫星、有文献根数的二体卫星、矮行星、小行星、彗星、HYG恒星，
以及已发布宿主星距离的系外行星系统。Astronomy Engine天体保留计算置信度。其余太阳系天体使用地图中
同一组JPL平均或振切轨道根数，迭代求解从地球接收的延迟；结果因而明确标为外推。视觉距离放大绝不参与
光行时计算。

对于系外行星系统，
[NASA PSCompPars系统距离](https://exoplanetarchive.ipac.caltech.edu/docs/API_PS_columns.html)按照
[IAU秒差距定义](https://www.iau.org/static/resolutions/IAU2015_English.pdf)转换为宿主星与所有行星共享的
太阳系质心延迟。该图层不重建宿主星自行，因此其静态目录方向不变。局部行星轨道会在共同发射时刻计算，
但相位、方向与显示比例仍明确属于示意，并非观测星历。没有发布距离的系统保持同时刻。星系和大尺度结构也在
现在使用各自的接收光契约。

具有目录距离的近邻星系使用几何光行时，同时保持静态三维位置。Cosmicflows-4距离模数按光度距离解释，
大尺度结构的显示距离按共动距离解释。两者都在同一个有文档说明的平直ΛCDM模型
（H0=70 km/s/Mpc、Ωm=0.3、ΩΛ=0.7）中反演，再应用
[宇宙学回望时间](https://arxiv.org/abs/astro-ph/9905116)。天体卡片显示推断出的模型红移和所用距离类型。
这只改变发射时刻，不改变目录位置或静态外观。

这是包含有限宇宙学近似的光速模型，并非完整的相对论或星系演化模型。HYG匀速运动外推限制在±10,000儒略年，达到边界时
会明确标注。

地球观测者天象仪仍是独立的站心投影。它使用所选地点计算高度角、方位角、地形遮挡和视角直径；
选择接收到的光并不会把3D地图变成该天象仪。

## 位置与自转

行星和月球的位置由Astronomy Engine在浏览器中计算。部分小天体和卫星使用有文献依据的
轨道根数或简化位置提供器，天体卡片会标注对应可信度。支持的天体采用随日期变化的轴向
姿态，包括逆行自转。纹理对齐和可见尺寸仍属于渲染适配。

## 食事件浏览器

浏览器覆盖地球–月球系统的日食与月食。它可以把模拟移动到事件时刻、聚焦相关天体，并
为预设法国地点或手动输入的经纬度计算局地情况。自定义坐标只在浏览器内使用；由于不会
调用地理编码或时区服务，时间以UTC显示。

日食视图区分日偏食、日环食和日全食，显示月球–地球–太阳几何、半影和中心路径，还会
显示C1、C2、食甚、C3和C4，并明确标注地平线以下的接触。只有观测地点进入全食或环食时
才会出现C2和C3。月食视图表现月球进入地球阴影的过程。

::: warning 解读提示
为了可读性，轨道场景会夸大部分半径和间隔。地表覆盖层是教育性重建，不是业务级预报。
规划观测和保护眼睛时，请始终查阅权威天文服务。
:::

长时间外推、历史重建和宇宙学时间会明确标记为外推、模拟或示意，不会作为精确观测呈现。
