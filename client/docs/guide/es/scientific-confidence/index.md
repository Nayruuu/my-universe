# Fiabilidad científica

Universe Map no trata todos los elementos visibles como igualmente ciertos. Cada objeto o
representación utiliza uno de seis niveles.

## Niveles de fiabilidad

| Nivel          | Significado                                             | Ejemplo                                           |
| -------------- | ------------------------------------------------------- | ------------------------------------------------- |
| `observed`     | Medición o catálogo publicado                           | Dirección de una estrella o distancia galáctica   |
| `calculated`   | Cálculo astronómico                                     | Posición planetaria en la fecha elegida           |
| `extrapolated` | Extensión de un movimiento medido u órbita simplificada | Movimiento propio fuera de la época de referencia |
| `simulated`    | Modelo científico o de continuidad                      | Envolvente opcional de densidad cósmica           |
| `procedural`   | Generado para completar una representación              | Partículas dentro de una galaxia adaptada         |
| `illustrative` | Diseñado para legibilidad, no a escala física           | Radio visual, brillo o línea de constelación      |

La ficha muestra el nivel y notas de la fuente. Una misma vista puede combinar posición observada,
orientación calculada y tamaño aparente ilustrativo.

## Coordenadas científicas y visuales

Las fuentes conservan unidades explícitas: kilómetros, unidades astronómicas, años luz, pársecs,
kilopársecs y megapársecs. El motor las convierte en marcos jerárquicos. Los radios visuales y algunas
distancias entre escalas se adaptan aparte porque una escala física global ocultaría casi todos los
cuerpos.

## Épocas, marcos y realismo

Las posiciones pertenecen a épocas y marcos documentados: J2000, efemérides heliocéntricas, modelos
galactocéntricos o posiciones derivadas del corrimiento al rojo. La aplicación no fusiona estudios
incompatibles en una supuesta geometría exacta.

Texturas, bloom, atmósferas, emisión de acreción, morfología galáctica, colores de supernova y lentes
de agujeros negros facilitan la comprensión, pero no son mediciones. La lente es cualitativa, las
constelaciones son convenciones culturales, la continuidad cósmica no resuelta es simulada y las
partículas galácticas pueden ser ilustrativas.

Universe Map sirve para explorar, aprender y comparar visualmente, no para navegación espacial,
astrometría profesional, seguridad de observación o predicción precisa de eclipses.
