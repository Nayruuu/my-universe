# Acerca de Universe Map

Universe Map es un proyecto independiente imaginado, diseñado y desarrollado por **Nayruuu**. Su
objetivo es acercar la escala y la riqueza del Universo mediante un mapa interactivo continuo, sin
dejar de explicar la diferencia entre datos observados, cálculos astronómicos, simulaciones y
adaptaciones visuales.

El proyecto combina arquitectura de software, preparación de datos científicos, renderizado 3D en
tiempo real, diseño de interfaces, accesibilidad, optimización, documentación y traducción. Se ofrece
como una aplicación web estática y gratuita para que cualquier persona con un navegador moderno
pueda comenzar a explorar sin una cuenta ni programas especializados.

## ¿Por qué crear este mapa?

La mayoría de las herramientas astronómicas se concentran en una escala concreta: el cielo visto
desde la Tierra, un sistema planetario o un catálogo pensado para el análisis científico. Universe
Map explora una idea complementaria: una sola experiencia cartográfica capaz de viajar desde una
luna hasta el Sistema Solar, las estrellas cercanas, la Vía Láctea, las galaxias y las estructuras
documentadas de la red cósmica.

Esta ambición no significa que cada imagen sea una representación literal de la realidad. La
legibilidad exige a veces tamaños adaptativos, densidad procedural, transiciones o materiales
ilustrativos. Estas decisiones se identifican para que la belleza visual y la transparencia
científica puedan convivir.

## Apoyar el viaje

Universe Map es de acceso gratuito y su código fuente está disponible en
[GitHub](https://github.com/Nayruuu/my-universe). Un café nunca es necesario para explorar, pero ayuda
a dedicar más tiempo a mejorar los catálogos astronómicos, las pruebas científicas, la calidad
visual, la accesibilidad, las traducciones, la documentación y el recorrido entre escalas
planetarias y cosmológicas.
