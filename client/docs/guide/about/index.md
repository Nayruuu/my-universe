# About Universe Map

Universe Map is an independent project imagined, designed, and developed by **Nayruuu**. Its goal is
to make the scale and richness of the Universe approachable through a continuous interactive map,
while remaining honest about the difference between observed data, astronomical calculations,
simulations, and visual adaptations.

The project brings together software architecture, scientific data preparation, real-time 3D
rendering, interface design, accessibility, performance work, documentation, and translation. It is
built as a free static web application so that anyone with a modern browser can begin exploring
without an account or specialist software.

## Why build it?

Most astronomy tools focus on one particular scale: a sky as seen from Earth, a planetary system,
or a catalogue intended for scientific analysis. Universe Map explores a complementary idea: one
cartographic experience that can move from a moon to the Solar System, nearby stars, the Milky Way,
galaxies, and documented structures of the cosmic web.

That ambition does not mean presenting every visual as literal reality. Readability sometimes
requires adaptive sizes, procedural density, transitions, or illustrative materials. These choices
are documented so that visual wonder and scientific transparency can coexist.

## Supporting the journey

Universe Map is free to explore and its source code is available on
[GitHub](https://github.com/Nayruuu/my-universe). A coffee is never required, but it helps create more
time for improving astronomical catalogues, scientific tests, rendering quality, accessibility,
translations, documentation, and the long journey between planetary and cosmological scales.
