## One map, several representations

No single physical scale can display the Earth, the Solar System, the Milky Way, and the observable
Universe at the same time. Universe Map therefore uses hierarchical reference frames, semantic zoom,
adaptive object sizes, and levels of detail. The visual representation changes continuously while the
scientific source unit and confidence remain attached to each object.

This guide explains how to use the map and how to interpret it. Start with
[Getting started](/getting-started/), then read [Scientific confidence](/scientific-confidence/) to
understand the boundary between astronomical data and visual cartography.

::: warning Prototype
Universe Map is an educational scientific visualisation, not a professional ephemeris, spacecraft
navigation system, or complete model of the Universe.
:::

## What is currently mapped?

- the Sun, eight planets, selected moons, dwarf planets, asteroids, and comets;
- local planetary and lunar motion through time;
- 6,333 confirmed exoplanets around 4,747 catalogue hosts;
- 10,000 selected HYG stars and all 88 modern constellation figures;
- historical supernovas, remnants, and selected black holes;
- the Milky Way, 31 Local Group galaxies, and 720 nearby galaxies;
- Cosmicflows-4 groups and several published catalogues of clusters, superclusters, voids, and
  filament spines.

Continue with [Navigation and scale](/navigation/) for the complete map hierarchy.
