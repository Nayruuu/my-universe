# Universe Map 프로젝트 소개

Universe Map은 **Nayruuu**가 직접 구상하고 디자인하며 개발하는 독립 프로젝트입니다. 관측
데이터, 천문 계산, 시뮬레이션, 시각적 보정을 명확히 구분하면서도 우주의 거대한 규모와
다양성을 하나의 연속적인 인터랙티브 지도로 누구나 쉽게 경험할 수 있도록 만드는 것이
목표입니다.

이 프로젝트에는 소프트웨어 아키텍처, 과학 데이터 정제, 실시간 3D 렌더링, 인터페이스
디자인, 접근성, 성능 최적화, 문서화, 번역 작업이 함께 담겨 있습니다. 계정이나 전문
프로그램 없이도 최신 브라우저만 있으면 바로 탐험할 수 있도록 무료 정적 웹 애플리케이션으로
제공됩니다. 서버 기반의 개인 데이터 수집보다 브라우저에서 직접 실행되는 가볍고 투명한
경험을 우선합니다.

## 왜 이런 지도를 만들까요?

많은 천문 도구는 지구에서 바라본 하늘, 하나의 행성계, 또는 과학 분석용 카탈로그처럼 특정
규모에 집중합니다. Universe Map은 이와 다른 보완적인 질문에서 시작합니다. 하나의 지도
경험 안에서 달과 행성에서 출발해 태양계, 가까운 별, 우리은하, 주변 은하, 그리고 문서화된
우주 거대 구조까지 자연스럽게 이동할 수 있다면 우주를 어떻게 이해하게 될까요?

모든 화면을 문자 그대로의 현실이라고 주장하지는 않습니다. 서로 엄청나게 다른 규모를 읽기
쉽게 연결하려면 적응형 크기, 절차적으로 생성한 밀도, 부드러운 전환, 설명 목적의 재질이
필요할 때가 있습니다. 이러한 선택에는 신뢰도와 출처를 표시해 시각적 경이로움과 과학적
투명성이 함께 유지되도록 합니다.

## 탐험을 후원하는 방법

Universe Map은 누구나 무료로 이용할 수 있으며 소스 코드는
[GitHub](https://github.com/Nayruuu/my-universe)에 공개되어 있습니다. 커피 후원은 탐험에
필수 조건이 아니지만, 더 정확한 천문 카탈로그와 과학 테스트, 아름다운 렌더링, 접근성,
다국어 번역, 문서, 행성 규모와 우주론적 규모 사이의 긴 전환을 개선하는 데 더 많은 시간을
쓸 수 있도록 도와줍니다.

Nayruuu의 다른 소프트웨어와 인터랙티브 프로젝트는
[super-dev.app](https://super-dev.app)에서 확인할 수 있습니다.
