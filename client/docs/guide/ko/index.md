## 하나의 지도, 여러 표현 방식

지구와 태양계, 우리은하, 관측 가능한 우주를 하나의 물리적 축척으로 동시에 보여 줄 수는
없습니다. Universe Map은 계층형 좌표계, 의미 기반 줌, 적응형 천체 크기와 세부 수준(LOD)을
사용합니다. 화면 표현은 연속적으로 바뀌지만 원래의 과학 단위와 신뢰도는 각 천체에
그대로 연결됩니다.

이 가이드는 지도를 사용하고 해석하는 방법을 설명합니다. 먼저
[시작하기](/ko/getting-started/)를 읽고, [과학적 신뢰도](/ko/scientific-confidence/)에서
천문 데이터와 시각적 지도 표현의 경계를 확인하세요.

::: warning 프로토타입
Universe Map은 교육용 과학 시각화입니다. 전문 천체력, 우주선 항법 시스템 또는 우주의
완전한 모형으로 사용할 수 없습니다.
:::

## 현재 지도에 포함된 항목

- 태양, 여덟 행성, 주요 위성, 왜행성, 소행성, 혜성;
- 시간에 따른 행성과 달의 국부 운동;
- 4,747개 호스트 항성 주위의 확인된 외계행성 6,333개;
- 선별한 HYG 별 10,000개와 현대 88개 별자리;
- 역사적 초신성, 초신성 잔해와 일부 블랙홀;
- 우리은하, 국부은하군 은하 31개와 가까운 은하 720개;
- Cosmicflows-4 은하군과 공개된 은하단·초은하단·우주 공동·필라멘트 카탈로그.

전체 계층은 [탐색과 축척](/ko/navigation/)에서 확인할 수 있습니다.
