# 과학적 신뢰도

Universe Map은 화면에 보이는 모든 요소를 같은 수준의 사실로 취급하지 않습니다. 천체와
표현에는 다음 여섯 신뢰도 중 하나가 붙습니다.

## 신뢰도 단계

| 단계           | 의미                             | 예시                         |
| -------------- | -------------------------------- | ---------------------------- |
| `observed`     | 측정 또는 공개 카탈로그 기반     | 별의 방향, 은하 거리         |
| `calculated`   | 천문 계산에서 도출               | 선택 날짜의 행성 위치        |
| `extrapolated` | 측정 운동 또는 단순 궤도의 연장  | 기준 시점 밖의 고유운동      |
| `simulated`    | 과학 또는 연속성 모형의 결과     | 선택형 우주 밀도 외피        |
| `procedural`   | 화면 표현을 채우기 위해 생성     | 적응형 은하 내부 입자 배치   |
| `illustrative` | 물리 축척보다 가독성을 위한 표현 | 시각 반지름, 광휘, 별자리 선 |

천체 카드에는 단계와 출처별 설명이 표시됩니다. 하나의 천체도 관측 위치, 계산된 방향,
설명용 겉보기 크기를 동시에 사용할 수 있습니다.

## 과학 좌표와 시각 좌표

원본 데이터는 킬로미터, 천문단위, 광년, 파섹, 킬로파섹, 메가파섹 같은 명시적 단위를
보존합니다. 엔진은 계층형 좌표계 안에서 변환합니다. 전역 물리 축척만 쓰면 대부분의
천체가 한 픽셀보다 작아지므로 시각 반지름과 일부 축척 간 거리는 별도로 조정됩니다.

## 기준 시점과 시각적 사실성

카탈로그 위치는 J2000 항성 좌표, 태양 중심 행성력, 은하 중심 모형, 적색편이 기반 위치
같은 문서화된 기준계와 시점에 속합니다. 서로 호환되지 않는 관측 자료를 하나의 정확한
기하라고 합치지 않습니다.

텍스처, 블룸, 대기, 강착 방출, 은하 형태, 초신성 색과 블랙홀 렌즈는 이해를 돕지만 측정
자료는 아닙니다. 블랙홀 렌즈는 정성적이고 별자리 선은 문화적 관습이며, 미해상 우주
연속성은 시뮬레이션되고 은하 입자 배치는 설명용일 수 있습니다.

이 지도는 탐색·교육·시각 비교에 적합하지만 우주선 항법, 전문 측성학, 관측 안전 판단이나
정밀한 식 예측에는 적합하지 않습니다.
