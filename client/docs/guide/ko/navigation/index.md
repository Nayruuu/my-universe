# 탐색과 축척

Universe Map은 고정된 궤도 그림이 아니라 공간 지도처럼 동작합니다. 카메라 속도, 최소
거리, 레이블, 천체 표현과 배경 레이어가 현재 천문 맥락에 맞춰 변합니다.

## 조작 방법

| 동작               | 데스크톱                      | 터치                 |
| ------------------ | ----------------------------- | -------------------- |
| 대상 주위 회전     | 왼쪽 클릭 후 드래그           | 한 손가락 드래그     |
| 평행 이동          | 오른쪽 클릭 후 드래그         | 두 손가락 드래그     |
| 포인터 방향 줌     | 마우스 휠                     | 핀치                 |
| 선택               | 천체 또는 이름 클릭           | 천체 또는 이름 탭    |
| 포커스             | 더블 클릭, 이름 클릭 또는 `F` | 더블 탭 또는 이름 탭 |
| 시간 재생·일시정지 | `스페이스`                    | 타임라인 버튼        |
| 시간 속도 변경     | `+` 또는 `-`                  | 타임라인 선택기      |
| 카드 닫기          | `Escape`                      | 닫기 버튼            |

휠 줌은 화면 포인터 방향으로 진행합니다. 안쪽으로 향하는 동작을 탐색 가능한 천체의 이름이나
표시 위에서 시작하면, 그 천체가 동작 전체에 잠기고 탐색 대상이자 줌 기준점이 됩니다. 접근은
연속적으로 진행되어 상황별 최소 거리 앞에서 멈추므로 같은 동작의 추가 입력으로 천체를 통과할 수
없습니다. 자동 축척 전환은 지도 계층에 필요한 논리적 상위 또는 하위 대상으로 바꿀 수 있습니다.
빈 공간에서는 기하학적 회전 중심이 포인터를 따릅니다. 도달한 대상은 포인터가 더 이상 그 천체를
가리키지 않을 때만 해제되며, 선택한 카드를 닫지 않고 카메라와 중심을 일정한 거리로 이동할 수
있습니다. 반대 방향으로 돌리면 이 자유 이동을 되돌린 뒤 축소를 다시 시작합니다.

## 일곱 지도 축척

| 축척           | 대표 내용                         | 주 표현 방식                          |
| -------------- | --------------------------------- | ------------------------------------- |
| 행성           | 표면, 대기, 고리, 위성            | 상세 메시와 텍스처                    |
| 태양계         | 태양, 행성, 소천체, 궤도          | 적응형 메시, 레이블과 궤적            |
| 항성 근방      | HYG 별, 외계행성 호스트, 별자리   | GPU 포인트 배치와 선택 상세           |
| 우리은하       | 원반, 팽대부, 나선팔, 태양계 위치 | 층형 발광 볼륨과 카탈로그 맥락        |
| 국부은하군     | 우리은하, 안드로메다와 위성 은하  | 은하 임포스터와 제한된 입자 볼륨      |
| 가까운 우주    | 국부 부피의 은하와 은하군         | 정적 공간 타일과 개요 배치            |
| 우주 거대 구조 | 은하군, 은하단, 공동과 필라멘트   | 카탈로그 점·선과 시뮬레이션 밀도 볼륨 |

전환은 연속적이지만 각 축척은 다른 내부 좌표계를 사용합니다. 렌더러는 수치 정밀도를
유지하기 위해 필요할 때 카메라 주변으로 원점을 옮깁니다.

## 대상, 선택과 레이블

**논리적 대상**은 의미적 경로와 상황별 거리 제한을 관리합니다. **기하학적 회전 중심**은
카메라가 주변을 도는 중심이며 포인터 줌을 따릅니다. **선택**은 정보 카드의 천체, **레이블**은 충돌을
피하도록 관리되는 화면 주석입니다. 레이블을 클릭하면 천체를 선택하고 포커스합니다. 이름 밀도는
최소·균형·조밀 중에서 고를 수 있으며 대상, 선택과 주요 기준점이 우선됩니다. 국부 항성
축척까지는 태양이, 그보다 먼 곳에서는 우리은하가 상위 기준점으로 남습니다.

축척 메뉴를 이용하면 검색과 같은 부드러운 보간으로 원하는 단계에 바로 갈 수 있습니다.
화면이 비어 보이면 축척과 레이블을 확인하고 이름 밀도를 높이거나 태양·우리은하를
선택하세요. 기기가 느리다면 그래픽 품질을 낮추세요.
