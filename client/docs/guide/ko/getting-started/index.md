# 시작하기

Universe Map은 최신 브라우저에서 완전히 실행됩니다. 계정이나 애플리케이션 백엔드가
필요하지 않습니다. 천문 카탈로그, 텍스처와 모델은 정적 파일로 제공되며 카메라 축척에
맞춰 점진적으로 불러옵니다.

## 지도 열기

[super-universe.app](https://super-universe.app/ko/)에 접속하세요. 처음에는 렌더링 엔진과
작은 매니페스트만 읽고, 큰 항성·은하 데이터는 실제로 필요한 시점에 내려받습니다.

처음 사용할 때는 다음을 권장합니다.

1. WebGL 2를 지원하는 최신 데스크톱 브라우저를 사용합니다.
2. 최근 GPU라면 그래픽 품질을 **높음**으로 둡니다.
3. 로딩 화면이 사라질 때까지 기다립니다.
4. 보이는 천체 위에서 스크롤하거나 이름을 클릭합니다.

터치 탐색도 지원하며 작은 기기에서는 시각 밀도가 자동으로 줄어듭니다.

## 인터페이스 둘러보기

| 영역          | 기능                                                                   |
| ------------- | ---------------------------------------------------------------------- |
| 상단 검색     | 행성, 위성, 별, 외계행성, 은하, 블랙홀, 초신성과 거대 구조를 찾습니다. |
| 축척 경로     | 현재 천문 계층을 보여 주고 상위 단계로 바로 이동합니다.                |
| 천체 카드     | 출처, 별칭, 물리량, 신뢰도와 포커스 동작을 표시합니다.                 |
| 플로팅 컨트롤 | 줌, 지구·태양 복귀, 궤도·별자리·이름 표시를 제어합니다.                |
| 타임라인      | UTC 시간, 재생·일시정지, 속도, 식 현상 목록을 제어합니다.              |
| 지도 축척     | 현재 카메라에 맞춘 화면상 축척을 표시합니다.                           |

## 첫 여행

1. **지구**를 검색해 결과를 선택합니다.
2. 휠이나 핀치로 태양계 바깥쪽을 향해 줌합니다.
3. **태양**을 선택하고 항성 근방까지 계속 축소합니다.
4. 축척 메뉴에서 **우리은하**를 선택합니다.
5. 국부은하군, 가까운 우주, 우주 거대 구조까지 이동합니다.
6. 계층 경로로 태양계에 돌아옵니다.

논리적 대상은 지도 계층과 거리 제한, 기하학적 회전 중심은 카메라의 주회 중심, 선택 항목은
정보 카드를 결정합니다. 명시적으로 초점을 맞추면 보통 세 요소가 정렬되지만, 포인터 줌과 자유 공간
탐색 중에는 달라질 수 있습니다.

## 지상 지평선에서 별 관측하기

**시리우스** 같은 별을 검색하고 정보 카드를 연 뒤 **지구에서 찾기**를 선택합니다. 현지
하늘 보기는 지도의 날짜와 관측 위치를 사용합니다. 드래그해 둘러보고 휠이나 핀치로 시야를
바꾸며 **다시 가운데로**를 눌러 대상을 되찾을 수 있습니다. 이것은 플라네타륨 조작입니다.
지평선 보기가 열려 있는 동안 휠은 의미적 지도 축척 전환이나 최소 거리 이동을 시작하지 않습니다.
위치 선택기는 전 세계 461개의 정적 관측 장소를 제공하고, 관측자와 플라네타륨 보기는 공유 URL에
유지됩니다. **내 위치 사용**은 선택한 경우에만 브라우저 권한을 요청하고, 얻은 좌표를 소수점 셋째
자리(약 100m)로 반올림한 뒤 동일한 공유 가능 관측자 계약을 사용합니다.

달과 보이는 행성은 지도 보기와 같은 Three.js 객체, 재질, 조명, 출처가 있거나 조정된 텍스처를
재사용합니다. 선택한 장소와 시각에 대해 관측지 중심 방향과 각지름을 계산합니다. 작은 행성을 알아볼
수 있게 하는 제한된 최소 표시 크기는 실제 각지름이라는 뜻이 아니라 명시적인 설명용 표현입니다.

지평선은 시선 방위각을 따르면서 지면에 고정되고 하늘은 시간에 따라 움직입니다. 주요 도시
8곳에는 손으로 구성한 시각적 맥락이 있으며, 카탈로그의 각 장소는 지역별 정적 팩에서 인근
랜드마크 4개를 필요할 때 불러옵니다. 이름·좌표·높이에 출처가 있어도 렌더링이 측량 자료라는
뜻은 아닙니다. 지형, 도시 조명, 스카이라인 층과 일반 윤곽은 명시적으로 설명용입니다. 이
보기는 측량된 지형 차폐, 날씨 자료, 역사적 도시 복원 또는 전문 관측 계획 도구를 대신하지
않습니다.

## 품질과 공유

**낮음**은 입자·텍스처·볼륨·타일을 줄이고, **중간**은 세부와 GPU 비용을 조절하며,
**높음**은 현재 축척에서 허용된 가장 풍부한 표현을 사용합니다. 품질은 과학 좌표나
신뢰도를 바꾸지 않습니다.

공유 버튼은 대상, 선택, 날짜, 줌, 시간 모드, 품질, 이름 밀도, 궤도, 별자리와 레이블을
URL에 보존합니다. URL은 매 프레임이 아니라 짧은 지연 뒤 갱신됩니다.
