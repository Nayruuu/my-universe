# 時間と食

タイムラインは内部で数値のユリウス日を使用します。画面で入力したUTCの暦日は、
レンダリングエンジンへ送る前に変換されます。

## 時間操作

UTC日時の入力、再生・一時停止、現在時刻への復帰、スケールに応じた速度選択、記録済みの
過去・未来の食イベントの閲覧ができます。一時停止中は公転位置と自転軸の向きも固定
されます。再開後はフレーム数ではなく同じ内部時刻から両方を算出します。

## 時間モード

**選択日時の状態**は、すべての天体を一つの共通時刻に置いた推定状態を表示する、現在の
主要モードです。

**受信した光**では、選択日時を受信日時として扱います。対応する太陽系天体は地球から、
HYG恒星は太陽系重心から観測します。各対応天体を固有の放射日時で計算し、自転も同じ日時を
使います。天体カードには計算した光行時間と放射日時を表示します。

現在の対象は太陽、月、惑星、ガリレオ衛星、公開軌道要素を使う二体衛星、準惑星、小惑星、彗星、
HYG恒星、および主星距離が公開された系外惑星系です。Astronomy Engine天体は計算済みの信頼度を
保ちます。その他の太陽系天体は、地図と同じJPLの平均または接触軌道要素で、地球に届く遅延を
反復計算します。その結果は外挿と明記し、表示用の距離強調は光行時計算に使いません。

系外惑星系では、
[NASA PSCompParsの系距離](https://exoplanetarchive.ipac.caltech.edu/docs/API_PS_columns.html)を
[IAUのパーセク定義](https://www.iau.org/static/resolutions/IAU2015_English.pdf)に従って変換し、主星と
全惑星で共通の太陽系重心基準遅延を使います。このレイヤーは固有運動を再構成しないため、主星の静的な
カタログ方向は変わりません。局所惑星軌道は共通の放射日時で評価しますが、位相、向き、表示スケールは
引き続き説明用で、観測エフェメリスではありません。距離未公開の系は同時刻のままです。銀河と大規模構造も
個別の受信光契約を使うようになりました。

カタログ距離がある近傍銀河は、静的な3D位置を動かさず幾何学的光行時間を使います。Cosmicflows-4の
距離モジュラスは光度距離、大規模構造の表示距離は共動距離として解釈します。両者を同じ文書化済みの
平坦ΛCDMモデル（H0=70 km/s/Mpc、Ωm=0.3、ΩΛ=0.7）で逆算し、
[宇宙論的ルックバック時間](https://arxiv.org/abs/astro-ph/9905116)を適用します。天体カードは推定した
モデル赤方偏移と使用した距離種別を示します。放射時刻のみが変わり、カタログ位置と静的外観は変わりません。

これは限定的な宇宙論近似を含む有限光速モデルであり、完全な相対論・銀河進化モデルではありません。HYGの等速運動外挿は
±10,000ユリウス年に制限され、境界に達した場合は明示します。

地球観測者プラネタリウムは別の観測地点中心投影です。高度、方位角、地形遮蔽、見かけの角直径
には選択地点を使い、受信した光を選んでも3Dマップがこのプラネタリウムに変わるわけではありません。

## 位置と自転

惑星と月の位置はAstronomy Engineでブラウザ内計算します。一部の小天体や衛星は公開
軌道要素または簡略化プロバイダーを使い、カードに信頼度を表示します。対応天体の
自転軸方向は日時に応じて変わり、逆行自転も含みます。テクスチャの向きと画面上の
サイズは描画上の調整です。

## 食イベントブラウザー

地球–月系の日食と月食を扱います。イベント時刻へ移動し、関係天体をフォーカスし、
フランスの定義済み地点または手入力した緯度・経度について局地的な状況を計算できます。
独自座標はブラウザー内だけで使われ、ジオコーディングやタイムゾーンのサービスを
呼び出さないためUTCで表示されます。

日食ビューは部分・金環・皆既の分類、月–地球–太陽の配置、半影と中心食帯に加えて、
C1、C2、最大、C3、C4を表示し、地平線下の接触を明示します。C2とC3は、その地点で
皆既または金環になる場合だけ存在します。月食ビューは月が地球の影に入る様子を示します。

::: warning 解釈上の注意
軌道シーンは読みやすさのため一部の半径と距離を誇張します。地表レイヤーは教育用の
再構成であり、運用上の予報ではありません。観測計画と目の安全については必ず公的な
天文サービスを確認してください。
:::

長期外挿、歴史的再構成、宇宙論的時刻は、正確な観測と誤解されないよう外挿・
シミュレーション・説明用として明示されます。
