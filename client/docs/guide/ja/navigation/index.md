# ナビゲーションとスケール

Universe Mapは固定された軌道図ではなく、空間地図として動作します。カメラ速度、最小
距離、ラベル、天体表現、背景レイヤーが現在の天文スケールに適応します。

## 操作

| 操作                   | デスクトップ                    | タッチ                 |
| ---------------------- | ------------------------------- | ---------------------- |
| ターゲット周囲を回転   | 左クリックしてドラッグ          | 1本指でドラッグ        |
| 平行移動               | 右クリックしてドラッグ          | 2本指でドラッグ        |
| ポインター方向へズーム | マウスホイール                  | ピンチ                 |
| 選択                   | 天体または名前をクリック        | 天体または名前をタップ |
| フォーカス             | ダブルクリック、名前、または`F` | ダブルタップまたは名前 |
| 時間の再生・停止       | `スペース`                      | タイムラインボタン     |
| 時間速度の変更         | `+`または`-`                    | タイムライン選択       |
| カードを閉じる         | `Escape`                        | 閉じるボタン           |

ホイールズームは画面上のポインター方向へ進みます。内向きの操作をナビゲーション可能な
天体の名前または表示上で始めると、その天体は操作中ずっと固定され、ナビゲーションターゲットと
ズームの基準点になります。接近は連続的に進み、状況別の最小距離の手前で停止するため、同じ操作の
追加入力で天体を通り抜けることはありません。自動スケール変更では、マップ階層に必要な論理的な
親または子へ置き換わることがあります。空間を指している場合は、幾何学的な回転中心がポインターを
追います。到達したターゲットは、ポインターがその天体を指さなくなった場合にだけ解放され、選択中の
カードを閉じずにカメラと中心を一定距離で移動できます。逆方向へ回すと、この自由移動を戻してから
ズームアウトを再開します。

## 七つのマップスケール

| スケール         | 主な内容                             | 表現                                 |
| ---------------- | ------------------------------------ | ------------------------------------ |
| 惑星             | 表面、大気、環、衛星                 | 詳細メッシュとテクスチャ             |
| 太陽系           | 太陽、惑星、小天体、軌道             | 適応メッシュ、ラベル、軌道線         |
| 恒星近傍         | HYG恒星、系外惑星の主星、星座        | GPU点群バッチと選択詳細              |
| 天の川銀河       | 円盤、バルジ、腕、太陽系位置         | 層状発光ボリュームとカタログ         |
| 局所銀河群       | 天の川、アンドロメダ、伴銀河         | 銀河インポスターと限定粒子ボリューム |
| 近傍宇宙         | 局所体積の銀河と銀河群               | 静的空間タイルと概要バッチ           |
| 宇宙の大規模構造 | 銀河群、銀河団、ボイド、フィラメント | カタログ点・線と模擬密度ボリューム   |

遷移は連続していますが、各スケールは異なる内部座標系を使用します。数値精度を保つ
ため、必要に応じてレンダラーがカメラ周辺へ原点を移動します。

## ターゲット、選択、ラベル

**論理ターゲット**はセマンティック経路と状況別の距離制限を管理します。**幾何学的な回転中心**は
カメラが周回する中心で、ポインターズームに追従します。**選択**は情報カードの天体、**ラベル**は衝突を
避けて配置される画面注釈です。ラベルをクリックすると選択とフォーカスを行います。
名前密度は最小・標準・高密度から選べ、ターゲット、選択、主要な目印を優先します。
局所恒星スケールまでは太陽、それより遠くでは天の川銀河が親の目印になります。

スケールメニューは検索と同じ補間で各段階へ直接移動できます。画面が空に見える場合は
スケールとラベルを確認し、名前密度を上げ、太陽または天の川銀河を選択してください。
動作が遅ければ品質を下げます。
