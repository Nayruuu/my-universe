# 性能と制限

Universe Mapは最新デスクトップで60 FPS、モバイルで30 FPSを目標とします。利用可能な
点をすべて同時表示することより、安定したフレーム時間を優先します。

## 描画負荷を制限する仕組み

- 恒星、系外惑星の主星、銀河群、大規模構造はGPUの点・線バッチを使います。
- 大型カタログの各レコードに個別Three.jsオブジェクトを作りません。
- カメラ連動の空間インデックスが必要な恒星・銀河タイルだけ読み込みます。
- 詳細テクスチャとマテリアルは有効なLOD付近で読み込みます。
- 軌道計算の更新頻度を下げ、状態間を補間します。
- ラベルはスケール、品質、衝突に応じた予算を守ります。
- ボリューム効果は品質別のレイマーチとピクセル予算を使います。
- レンダーループはAngularの変更検出外で実行します。

## グラフィックプロファイル

| プロファイル | 用途                                 | 主な削減                                         |
| ------------ | ------------------------------------ | ------------------------------------------------ |
| 低           | スマートフォン、古いノートPC、省電力 | 点、テクスチャ、ボリュームサンプル、タイルを削減 |
| 中           | 内蔵GPUと一般利用                    | 密度とポスト処理を均衡                           |
| 高           | 最近のデスクトップ                   | より豊かなカタログ、テクスチャ、ボリューム、詳細 |

プロファイルは科学座標を変更しません。

## デバッグパネル

URLに`?debug=true`を加えると、FPS、ドローコール、三角形、ジオメトリ、テクスチャ、
可視天体、座標系、カメラ距離、ターゲット、ユリウス日、品質を表示します。

```text
https://super-universe.app/ja/?debug=true
```

JavaScript、WebGL 2、選択品質に十分なGPUメモリ、ポインターイベントが必要です。
カタログは全恒星・銀河を網羅せず、半径とスケール遷移は一部適応されます。観測可能な
モードは光の移動時間を完全にはモデル化せず、宇宙論サーベイの範囲も異なります。
未検出は物理的ボイドの証明ではなく、詳細な惑星表面、ライブ気象、厳密な相対論的
レイトレーシングは対象外です。

遅い場合は品質を下げ、GPUを使う他タブを閉じ、既知のターゲットへ戻ります。静的
データに失敗した場合はネットワークパネルで該当ファイルを確認してください。
