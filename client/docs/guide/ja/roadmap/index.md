# ロードマップ

_最終確認：2026年8月27日。_

このページはUniverse Mapの正式な公開ロードマップです。固定したリリース日を約束するのではなく、
成果と検証条件を示します。科学的精度、読みやすいナビゲーション、安定したフレーム時間、完全に
静的なブラウザー構成は、すべての項目に共通する制約です。

## ステータスの読み方

| 状態     | 意味                                                         |
| -------- | ------------------------------------------------------------ |
| 提供済み | 現在のアプリで利用でき、自動テストで保護されている           |
| 現在     | 既存の体験に対して次に改善する項目                           |
| 次       | 科学的な契約または実機測定を先に必要とする作業               |
| 延期     | 新しい出典・データ・高密度カタログがある場合にだけ有効な作業 |

## 提供済み

- **地球観測者プラネタリウム**では、自由に見回せるHYG恒星10,000個、現代星座、高度と方位角、
  ポインターに固定される102°〜2°の視野角、URLから復元できる461地点、同意後に小数第3位へ
  丸めるブラウザー位置情報、説明用の地域シーンを利用できます。
- 固定カタログ地点ごとに、権威あるNOAA/NCEI ETOPO 2022 v1 60秒角表面地形から計算した
  360°遮蔽プロファイルがあります。小さなプロファイルは必要時だけ読み込まれ、モデル地形の背後に
  ある恒星・月・惑星を隠します。建物、植生、微地形、自由座標地点はこのモデルの対象外です。
  計算された3つの距離層（0～30、30～100、100～300 km）がシルエットに奥行きを与え、色と照明は
  スタイル表現です。
- 月と見える7惑星は、既存のThree.jsオブジェクト、マテリアル、照明、遅延テクスチャを再利用します。
  地心ではなく観測地点からの方向と角直径を計算し、読みやすさの最小サイズは説明用と明記します。
- 恒星と銀河系はズームに応じて連続的に詳細化します。ナビゲーションは視覚的文脈を失ったターゲット
  と選択も解除します。
- HYGのJ2000直交速度により、共有恒星カタログ、観測者の空、星座図形を時間伝播します。
  信頼度は外挿と明示し、有効範囲は±10,000ユリウス年に制限します。
- 時間モード**受信した光**は、選択日時を受信日時として扱うようになりました。Astronomy Engineで
  地球から見た太陽、月、惑星を遡及計算し、太陽系重心から各HYG恒星固有の遅延日時を解きます。
  対応する自転はその放射日時を使い、天体カードに遅延と放射日時を表示し、HYGモデルは明示した
  ±10,000ユリウス年の制限を維持します。
- ガリレオ衛星は、地球に届いた時刻のAstronomy Engineを使います。その他の公開軌道要素を持つ衛星、
  準惑星、小惑星、彗星は、既存のJPL二体要素で幾何学的光行時を反復計算します。信頼度は外挿のままで、
  表示用の距離強調は科学計算に含みません。
- 文書化された系外惑星系は、NASAが公開した主星距離から得た太陽系重心基準の遅延を共有します。主星の
  静的方向は変えず、局所惑星軌道をその放射日時で評価しますが、位相は説明用と明記します。距離未公開の
  系は同時刻のままです。
- 公開された壁、確率的な引力圏、アトラクター、リペラーはTempelフィラメント網と統合せず、個別の
  出典と記号を保持します。
- コールドスタート、Tempel遷移、リソース安定性、フレーム安定性には再現可能なブラウザー
  ベンチマークがあります。

## 現在の優先事項

- 銀河と大規模構造について、出典に適した受信光の契約を定義します。距離を単純に光速で割るのではなく、
  宇宙論的なルックバック時間と赤方偏移の意味付けが必要です。

プラネタリウムは選択地点の独立した観測地点中心投影です。時間マップの受信した光は、対応する
太陽系天体には地球を、HYG恒星と文書化された系外惑星系には太陽系重心を使います。

## 次の測定に基づく投資

- 低・中・高性能を代表する実機で、Tempel遷移、起動、メモリ、フレームレートのベンチマークを
  実行します。シェーダー事前コンパイルや重い代替処理は、測定結果が費用を正当化するときだけ
  追加します。

## 意図的に延期

- 準備済みの集約恒星階層は、より高密度な原典カタログがスケール間の可視表現を必要とするまで
  休止します。有効化時は準備をWeb Workerへ移し、見えないネットワーク・GPU作業を避けます。
- 不規則天体の新しい輪郭やポリゴンモデルは、権威ある形状資料がダウンロード、デコード、帰属、
  描画コストを正当化する場合だけ追加します。
