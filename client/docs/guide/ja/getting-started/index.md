# 使い始める

Universe Mapは最新ブラウザ内で完結して動作します。アカウントもアプリケーション用
バックエンドも必要ありません。天文カタログ、テクスチャ、モデルは静的ファイルとして
提供され、カメラのスケールに応じて段階的に読み込まれます。

## マップを開く

[super-universe.app](https://super-universe.app/ja/)にアクセスしてください。最初の画面では
レンダリングエンジンと小さなマニフェストを読み込み、大きな恒星・銀河データは必要に
なった時点で取得します。

最初は次の環境を推奨します。

1. WebGL 2対応の最新デスクトップブラウザを使う；
2. 新しいGPUなら品質を**高**にする；
3. 読み込み表示が消えるまで待つ；
4. 見えている天体上でスクロールするか名前をクリックする。

タッチ操作にも対応し、小型端末では描画密度を自動的に下げます。

## 画面の構成

| 場所               | 役割                                                                               |
| ------------------ | ---------------------------------------------------------------------------------- |
| 上部検索           | 惑星、衛星、恒星、系外惑星、銀河、ブラックホール、超新星、大規模構造を検索します。 |
| スケール階層       | 現在の天文階層を示し、上位レベルへ直接移動します。                                 |
| 天体カード         | 出典、別名、物理量、信頼度、フォーカス操作を表示します。                           |
| フローティング操作 | ズーム、地球・太陽への復帰、軌道・星座・名前の表示を制御します。                   |
| タイムライン       | UTC時刻、再生・一時停止、速度、食イベントを操作します。                            |
| マップスケール     | カメラ状況に適応した画面上の尺度を示します。                                       |

## 最初の旅

1. **地球**を検索して結果を選択します。
2. ホイールまたはピンチで太陽系の外側へズームアウトします。
3. **太陽**を選び、恒星近傍までさらに移動します。
4. スケールメニューから**天の川銀河**を選びます。
5. 局所銀河群、近傍宇宙、宇宙の大規模構造へ進みます。
6. 階層表示から太陽系へ戻ります。

論理ターゲットはマップ階層と距離制限、幾何学的な回転中心はカメラの周回中心、選択は情報カードを
定めます。明示的なフォーカスでは通常この3つが一致しますが、ポインターズームや自由空間ナビゲーションでは
分かれることがあります。

## 地上の地平線から恒星を観察する

**シリウス**などの恒星を検索し、情報カードを開いて**地球から位置を確認**を選びます。
ローカル天空表示には、地図の日時と観測地点が使われます。ドラッグで見回し、ホイールや
ピンチで視野角を変え、**再中心化**でターゲットを戻せます。これらはプラネタリウム用の操作です。
地平線表示中、ホイールはセマンティックなマップスケール変更や最小距離での移動を起こしません。
地点選択には世界461か所の静的な観測地点があり、観測者とプラネタリウム表示は共有URLに保存されます。
**現在地を使用**は選択時にのみブラウザーの許可を求め、取得した座標を小数第3位（約100 m）に丸めて、
同じ共有可能な観測者の仕組みを使用します。

月と見える惑星は、マップ表示と同じThree.jsオブジェクト、マテリアル、照明、出典付きまたは
調整済みのテクスチャを再利用します。観測地点と日時に対する方向と角直径を計算します。小さな惑星を
確認できる制限付き最小表示サイズは、実際の角直径を示すものではなく、説明用と明記されます。

地平線は視線の方位角に追従して地面に固定され、空は時間とともに動きます。8つの主要
都市には手作業で構成した視覚コンテキストがあり、カタログの各地点では地域別の静的
パックから近隣のランドマーク4件を必要時に読み込みます。名称・座標・高さに出典が
あっても、表示が測量済みという意味ではありません。地形、街明かり、スカイライン層、
汎用的な輪郭は明示的に説明用です。測量された地形遮蔽、気象、歴史的都市復元、専門的な
観測計画の代わりにはなりません。

## 品質と共有

**低**は粒子・テクスチャ・ボリューム・タイルを減らし、**中**は詳細とGPU負荷の
バランスを取り、**高**は現在のスケールで許される最も豊かな表現を使用します。品質は
科学座標や信頼度を変えません。

共有ボタンはターゲット、選択、日時、ズーム、時間モード、品質、名前密度、軌道、星座、
ラベルをURLに保存します。URLは毎フレームではなく短い遅延後に更新されます。
