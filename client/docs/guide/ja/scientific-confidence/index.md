# 科学的信頼度

Universe Mapは画面に見えるすべてを同じ確度の事実として扱いません。各天体または表現に
は次の六つの信頼度のいずれかが付きます。

## 信頼度レベル

| レベル         | 意味                               | 例                         |
| -------------- | ---------------------------------- | -------------------------- |
| `observed`     | 測定または公開カタログに基づく     | 恒星の方向、銀河までの距離 |
| `calculated`   | 天文計算から導出                   | 選択日時の惑星位置         |
| `extrapolated` | 測定運動または簡略軌道を延長       | 基準元期外の固有運動       |
| `simulated`    | 科学モデルまたは連続性モデルの結果 | オプションの宇宙密度分布   |
| `procedural`   | 表現を補うために生成               | 適応銀河内の粒子配置       |
| `illustrative` | 物理スケールより可読性を優先       | 視覚半径、光彩、星座線     |

天体カードにはレベルと出典注記が表示されます。一つの天体に、観測位置、計算された
向き、説明用の見かけサイズが同時に使われることもあります。

## 科学座標と視覚座標

元データはキロメートル、天文単位、光年、パーセク、キロパーセク、メガパーセクなどの
明示的な単位を保持します。エンジンは階層座標系内で変換します。全体を物理スケールに
するとほぼすべてが1ピクセル未満になるため、視覚半径と一部のスケール間距離は別に
調整されます。

## 元期、座標系、視覚的リアリズム

カタログ位置はJ2000恒星座標、太陽中心の惑星暦、銀河中心モデル、赤方偏移由来位置など、
文書化された座標系と元期に属します。互換性のないサーベイを一つの正確な幾何として
統合しません。

テクスチャ、ブルーム、大気、降着放射、銀河形態、超新星色、ブラックホールレンズは
理解を助けますが測定ではありません。レンズは定性的で、星座線は文化的慣習、未解像の
宇宙連続性はシミュレーション、銀河粒子配置は説明用の場合があります。

本マップは探索・教育・視覚比較向けで、宇宙機航法、専門測星、観測安全判断、精密な
食予測には利用できません。
